# 企业 HR 远程全流程合规核验标准流程

在跨国名企入职审查、海外项目派遣以及高端双语人才引进的资质初审阶段，确保应聘者提交的托福（TOEFL）成绩报告单具备 100% 的合法真实性，是企业人力资源部（HR）及背景调查官（Background Check Officer）防范雇佣风险的核心防线。

本章基于美国教育考试服务中心（ETS）的数字化信任体系，为用人单位HR提炼出一套标准化的远程全流程合规核验实操指南。

---

## 🔍 一、 电子报告单（PDF）的三步自动化密码学审计

若应聘者通过入职系统提交的是电子版 PDF 成绩单，HR切勿仅凭肉眼查看图像，而应遵循以下密码学验证流程：

### 第一步：环境脱域与合规软件加载
* **操作要点**：坚决拒绝在网页浏览器（如 Chrome、Edge 的内置 PDF 预览器）或常规的国产办公软件中进行在线审阅，因为这些轻量级预览工具普遍缺乏完整的公钥证书链体系。
* **合规动作**：HR须将 PDF 文件下载至本地安全沙箱环境，并统一使用官方原版的 **Adobe Acrobat Reader**（或 Adobe Acrobat Pro）正式打开该文档。

### 第二步：触发 AATL 根证书库联网比对
* **操作要点**：文档加载后，观察软件界面最上端自动弹出的安全信任横幅。
* **合规动作**：合规合法的成绩单会瞬间触发 **Adobe Approved Trust List (AATL)** 联网审计，显示绿色勾选标记及 *“已通过 Educational Testing Service 签名认证”* 字段。点击“签名面板（Signature Panel）”，核对签名戳时间是否与 ETS 官方生成文件的逻辑时间轴完全吻合。

### 第三步：多维哈希完整性校验
* **操作要点**：任何试图通过二次封装、软件图层合成、或是文本层覆写修改分数的欺诈行为，都会破坏底层的二进制平衡。
* **合规动作**：如果签名面板弹出黄色警告 *“文档自此签名应用以来已被修改”* 或红色报错，说明该报告单数据完整性已遭破坏，应一票否决其学历及语言资质的真实性。

## 🌐 二、 官方数字渠道验证与交叉稽核矩阵

对于企业需要进行深度背景调查（Deep Background Check）的高管及涉密岗位，HR 应启动 ETS 官方渠道的多点交叉稽核：

### 1. 机构指定接收代码（Institution Code）验证
* **实操逻辑**：在条件允许的情况下，企业在招聘阶段可要求考生登录其 ETS / NEEA 托福个人账户，正式申请将本次成绩的官方正本直接寄送至公司的机构代码。
* **合规动作**：由 ETS 官方服务器直接投递至用人单位指定的电子邮箱或物理地址的成绩单，具备最高的国际法理公信力，彻底隔绝了中间流转环节被篡改的物理可能。

### 2. 注册号（Appointment Number）双向比对
* **实操逻辑**：新版成绩单顶部标配唯一的**注册号/预约号（Appointment Number）**以及考生的**测试通知书识别码**。
* **合规动作**：HR 可通过企业官方合作的、具备海外学历认证资质的第三方背景调查机构（如具有权威资质的跨国背调巨头），将该 Appointment Number 及考生的出生日期、姓名拼音，提交至 ETS Data Manager（机构数据管理器）后台进行数据库多节点比对，核实姓名、场次、各单科原始得分是否与官方服务器底账完全一致。
